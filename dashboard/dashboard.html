      My filters

      Write your own rules in Adblock Plus syntax. Elements you hide with the picker show up here.

      Ctrl + S

      Cheat sheet

      ||ads.example.com^
      Block a domain and its subdomains
      /banner/*$image
      Block matching images
      $third-party
      Only from other sites
      $domain=site.com
      Only on site.com
      @@||cdn.example.com^
      Never block this
      site.com##.promo
      Hide elements on site.com
      ##.cookie-bar
      Hide elements everywhere
      site.com#@#.promo
      Stop hiding on site.com
      ##div:has-text(Sponsored)
      Hide by text (site-specific)
      $removeparam=ref
      Strip a URL parameter
